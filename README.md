# LeNet-5 PyTorch

A PyTorch implementation of the classic LeNet-5 convolutional neural
network for handwritten digit classification using the MNIST dataset.

## Project Status

Currently under development.

## Architecture

The project implements a LeNet-5-inspired architecture consisting of:

- Convolutional layers
- Tanh activation
- Average pooling
- Fully connected layers
- 10-class output

## Tech Stack

- Python
- PyTorch
- Torchvision
- NumPy
- Matplotlib
- Scikit-learn
